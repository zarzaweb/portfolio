**Santiago Castañón Moreschi**

---

## Español

### Descripción

Portfolio personal desarrollado como proyecto propio para presentar mi perfil profesional, experiencia técnica y proyectos de desarrollo.

La aplicación está construida con Flask mediante una arquitectura modular, separando las rutas, extensiones y datos de los proyectos.

### Tecnologías utilizadas

- Python
- Flask
- Flask-Babel
- HTML5
- CSS3
- JavaScript
- Git

### Características técnicas

- Arquitectura modular mediante Flask Blueprints.
- Separación de rutas, extensiones y datos de los proyectos.
- Internacionalización español/inglés mediante Flask-Babel.
- Gestión de traducciones mediante Babel y gettext.
- Selección de idioma persistente mediante cookies.
- Plantillas dinámicas con Jinja2.
- Hojas de estilo organizadas por secciones.
- Presentación visual de proyectos, tecnologías y certificaciones.

### Estructura del proyecto

```text
Portfolios/
├── app.py
├── extensions.py
├── requirements.txt
├── data/
├── routes/
├── static/
│   ├── css/
│   ├── images/
│   ├── js/
│   └── screenshots/
├── templates/
└── translations/
```

## English

### Description

Personal portfolio developed as an individual project to showcase my professional profile, technical skills and software development projects.

The application is built with Flask using a modular architecture, separating routes, extensions and project data.

### Technologies

- Python
- Flask
- Flask-Babel
- HTML5
- CSS3
- JavaScript
- Git

### Technical features

- Modular architecture using Flask Blueprints.
- Separation of routes, extensions and project data.
- Spanish/English internationalization with Flask-Babel.
- Translation management using Babel and gettext.
- Persistent language selection through cookies.
- Dynamic templates with Jinja2.
- CSS stylesheets organized by sections.
- Visual presentation of projects, technologies and certifications.
